> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 사람마다 정한 규칙(개인/보고서형, 분·일·영업일 기준, 텔레그램·푸시)으로 웹앱이 직접 당번 알림을 보낸다.

```python
from datetime import time

SHIFT_TIMES: dict[str, tuple[str, str]] = {  # duty_notifier config 와 같은 값 (9시=석식교대, 저녁=야간)
    "dawn": ("06:30", "15:30"),
    "normal": ("08:00", "17:00"),
    "dinner": ("09:00", "18:00"),
    "night": ("13:30", "21:30"),
}

def _span(cell: str) -> tuple[str, str]:
    if is_slot_cell(cell):
        a, b = CONTROL_SLOTS[slot_index(cell)][0].split("~")
        return a, b
    return SHIFT_TIMES[cell]

def cell_start(cell: str) -> time:
    return time.fromisoformat(_span(cell)[0])

def cell_end(cell: str) -> time:
    return time.fromisoformat(_span(cell)[1])

def cells_of(keys: list[str]) -> list[str]:
    """스케줄 키(dawn..night, slots) → 칸 키. 빈 목록 = 전부. CELLS 순서."""
    if not keys:
        return list(CELLS)
    return [c for c in CELLS if (is_slot_cell(c) and "slots" in keys) or c in keys]
```

```python
DEFAULT_RULES = [

def normalize(kind, shifts, depts, types):
    def pick(vals, order):
        got = [v for v in order if v in set(vals)]

    if kind == "personal":
```

```python
"""알림 발송 시각 계산. ORM 없음, Asia/Seoul naive datetime."""
from datetime import date, datetime, time, timedelta

def bizdays_back(d: date, n: int) -> date:
    while n:
        d -= timedelta(days=1)
        if d.weekday() < 5:
            n -= 1
    return d

def send_at(timing: str, offset: int, at_minute: int, day: date, start: datetime) -> datetime:
    if timing == "before_start":
        return start - timedelta(minutes=offset)
    base = day - timedelta(days=offset) if timing == "days" else bizdays_back(day, offset)
    return datetime.combine(base, time(at_minute // 60, at_minute % 60))
```

```python
class RuleSpec:
    id: int
    member_name: str | None      # personal 규칙 주인의 멤버 이름(없으면 personal 무시)
    kind: str
    timing: str
    offset: int
    at_minute: int
    channels: tuple[str, ...]    # ("telegram",), ("push",), 둘 다
    shifts: tuple[str, ...]
    depts: tuple[str, ...]
    types: tuple[str, ...]

@dataclass(frozen=True)
class Due:
    rule_id: int
    date: date
    cell: str                    # 칸 키 또는 "report"
    channel: str
    title: str                   # 푸시 제목 (예: "당번 알림")
    text: str
    content_hash: str
    url: str                     # "/day/2026-11-16/"

def plan(rules: list[RuleSpec], days: list[Day], info: dict[str, tuple[str, str]],
         sent: dict[tuple[int, date, str, str], str], now: datetime) -> list[Due]
```
`info` = 이름 → (부서 코드, 유형). `sent` = (rule_id, date, cell, channel) → 마지막 content_hash.

**규칙**
- 개인: 규칙의 칸(`cells_of(shifts)`)마다 `start = combine(day, cell_start(cell))`, `at = send_at(...)`, `at <= now < start`일 때만.
  - 멤버가 그 칸에 있음: hash = `"in"`. 기록 없음 → 알림. 기록 hash ≠ `"in"`(전에 취소됨) → 다시 알림.
  - 멤버가 그 칸에 없음: 기록이 있고 hash == `"in"`이면 취소 알림, hash = `"out"`. 기록 없으면 아무것도 안 함.
- 보고서형: 하루 1건. 칸 = `cells_of(shifts)`, `start` = 그 칸들 시작의 최솟값, 발송 창 같음. 각 칸 이름을 `info`로 부서·유형 필터. 내용 hash = 표 내용 sha256(앞 16자 이상). 기록 없음 → `[출근표]`, 기록 hash 다름 → `[출근표 변경]`(전체 표 다시).
- 채널마다 별도 `Due`.

**문구 (`messages.py`)** — 요일 `"월화수목금토일"`:
- `day_label(d)` → `"11/16(월)"`; `relative_day(d, today)` → 오늘/내일/day_label.

**선행 변경 (Task 5 첫 단계, 모델·계획):**
- `AlarmDelivery`에 `last_sent_hash` CharField(64, null) 추가. 의미: `last_sent_hash` = 마지막으로 **성공**한 내용, `content_hash` = 마지막 **시도** 내용. 성공 → 둘 다 현재 hash, status sent, attempts 0, next_attempt_at None. 실패 → `last_sent_hash` 유지, `content_hash` = 현재, status failed.
