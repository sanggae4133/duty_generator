# 기획

NXT 당번표가 왜 생겼고, 누구를 위해 무엇을 하는지. 구현은 [ARCHITECTURE.md](ARCHITECTURE.md), 설계 원칙은 [PRINCIPLES.md](PRINCIPLES.md).

## 배경

IT 부서는 매일 출근조(새벽·정상·석식교대·야간)와 장중관제 당번(08:30~18:00, 10칸), 점심당번을 돌린다. 원래는 구글 시트 + Apps Script 로 관리했다. 시장관리본부 시장운영실(근무조 3개, 엑셀로 관리)도 같은 앱에서 근무표 하나로 운영할 예정이다(근무표마다 회차·배포·알림이 따로 돈다). 근무표를 더하는 절차는 [OPERATIONS.md](OPERATIONS.md) "근무표 추가하기".

- 부서마다 시트에 출근표를 채우고, 스크립트로 장중관제를 배정하고, 결과 시트를 공유했다.
- 근무를 바꾸면 시트 칸을 직접 고쳤다. 근무표 규칙(지난 날짜, 한 사람 하루 출근조 하나, 관제 자격)을 시트가 지켜 주지 않는다.
- 근무 알림은 별도 프로그램(노티파이어)이 시트를 읽어 보냈다. 알림이 시트 구조에 묶여 있었다.
- 휴대폰에서 시트로 내 근무만 골라 보기 어렵다.

## 목표

1. **시트를 완전히 대체한다.** 출근표 취합 → 장중관제 생성 → 배포 → 근무 변경 → 알림까지 한 곳에서.
2. **바뀐 것은 모두 남긴다.** 근무 변경, 회차 상태 변경에 누가·언제·무엇을 기록한다. 지난 날짜는 관리자만.
3. **휴대폰에서 바로 쓴다.** 내 근무 확인, 근무 바꾸기, 알림, 캘린더 구독.
4. **운영이 쉽다.** 서버 한 대, 프로세스 두 개, 설정 파일 하나, 데이터 폴더 하나. 처음 보는 개발자가 하루면 이해할 수 있게.
5. **사용법을 묻지 않아도 된다.** 화면만 보고 쓸 수 있게(HCI), 그래도 모르면 권한별 사용법 영상.

## 한 회차의 흐름

회차(Period)는 근무표를 만드는 단위다(시작일~종료일).

```
관리자: 회차 만들기(이름·기간) ─▶ 취합 열기
담당자: 부서 출근표 입력(날짜별 출근조에 사람)
관리자: 취합 마감 ─▶ 장중관제 생성(자동 배정, 편차 2 이하가 목표 — 자격자가 모자라면 미달로 표시) ─▶ 배포(덮어쓰기 시작일 선택)
멤버:   근무표·내 근무 확인, 알림 받기, 필요하면 근무 바꾸기(기록 남음)
관리자: 잘못 배포했으면 배포 취소(가장 최근 배포부터)
```

- 작성 중·마감 단계를 끈 근무표(시장운영실처럼 관리자가 출근표를 직접 넣는 팀)는 **입력 중 → 확정 → 배포됨**(단계를 켜고 끄는 것과 단계 이름은 근무표 설정): 회차를 만들면 바로 입력 중, 관리자가 표에 넣고(주마다 [2주 전 기준으로 채우기]·[지난주와 같게]) [확정]하면 배포할 수 있다. 확정을 되돌리려면 [확정 취소]. 주마다 채우기 버튼과 "빈 평일은 경고만(생성은 막지 않고, 누를 때 빈 날 수를 묻는다)"은 IT 를 포함한 모든 근무표에 같다.
- 회차끼리 기간이 겹치면, 나중에 배포한 회차가 덮어쓰기 시작일부터 앞 회차를 대신한다. 그래서 한 날짜의 근무표는 늘 하나다.
- 장중관제 자격: 개발자이고 그날 그 시간대의 자격 출근조(08:30 = 정상, 17:00 = 석식교대, 나머지 = 둘 다)에 있어야 한다.
- 점심당번은 생성할 때 그날 새벽 근무자로 채운다. 휴장일과 "근무 없음" 날은 채우기·생성이 건너뛰고, 필요한 사람만 직접 넣는다(입력 표, CSV에 그날 줄 추가, 근무 변경).

## 범위

**하는 것**: 여러 근무표, 회차·출근표 취합(표·CSV), 장중관제·점심당번 자동 생성, 배포·배포 취소, 근무 변경·맞교환과 기록, 사유(휴가·출장·교육), 메모(날·주·달, 근무 없음, 근무표마다 관리자가 켜는 메모 알림), 휴장일(공휴일 자동 + 관리 화면), 통계, 텔레그램·웹 푸시 알림, 캘린더(ICS) 구독, 엑셀 다운로드(근무표: 지금 화면의 기간·근무표·필터, 1년까지 / 내 근무: 고른 기간), 근무표 보기(주간·월간, 내 이름 강조·다른 사람 흐리게, 부서·유형·스케줄·변경 내역 필터의 보임·흐리게·숨김, 좌우로 밀어 넘기기), 글씨 크기, 권한별 도움말 영상.

**하지 않는 것** (필요해지면 그때 검토):

- 출근조 자동 배정: 출근조는 부서가 정한다. 자동 생성은 장중관제만.
- 외부 시스템 연동 API: 예전 노티파이어용 API 는 알림을 앱에 통합하면서 없앴다.
- 여러 서버·다른 DB: SQLite 한 대로 충분한 규모다(바꾸는 방법은 ARCHITECTURE.md "DB를 바꾸려면").
- 앱 화면의 드문 운영 일: 근무표 만들기(관리 화면 또는 `manage.py add_board`)·휴장일·알림 설정·로그인 잠금 해제·부서 만들기·관리자 계정 다루기는 슈퍼유저가 관리 화면에서 한다. 근무표 관리자의 일상 일은 [근무표 설정].
- 인사이동(사람의 부서·근무표 옮기기)을 앱 화면에서: 슈퍼유저가 관리 화면 사용자 → 부서에서 한다(개인 알림 발송 기록을 정리한다). 이름이 전체에서 고유해 옮길 사람을 새로 추가하는 우회는 막힌다.
- 지원 근무(다른 근무표에 하루 들어가기): 날 메모로 적는다.
- 사람·근무표 지우기, 근무표 code 바꾸기: 퇴사는 재직 끄기, 근무표는 지우지 않는다. 근무조 5개 이상은 칸 키를 늘리는 마이그레이션이 필요하다.
- 통계의 근무표 고르기: 장중관제를 쓰는 근무표가 하나뿐이라 아직 없다.

## 용어

| 용어 | 뜻 |
|---|---|
| 단계·켠 단계 | 회차 상태 다섯 값과 그 근무표의 화면 이름. 켠 단계 = 그 근무표가 쓰는 단계: (작성 중) → 취합 중 → (마감) → 생성됨 → 배포됨 |
| 회차 | 근무표를 만드는 기간 단위. 작성 중 → 취합 중 → 마감 → 생성됨 → 배포됨(근무표마다 작성 중·마감을 끌 수 있고 단계 이름을 정한다. 시장운영실은 입력 중 → 확정 → 배포됨) |
| 근무조 | 새벽(06:30~15:30)·정상·석식교대·야간. 한 사람은 하루 하나. 화면에서 옛 이름 '출근조'는 쓰지 않는다 |
| 근무 | 근무조·장중관제·점심당번을 아우르는 말. 필터·알림 규칙의 '근무' 체크(옛 '스케줄') |
| 출근표 | 부서가 회차마다 날짜별 근무조에 사람을 적어 내는 표(취합) |
| 구분 | 직원·개발자(장중관제 자격). 필터의 옛 이름 '유형'은 쓰지 않는다 |
| 관리자 | 근무표 관리자(근무표마다). 관리 화면([관리])을 쓰는 사람은 슈퍼유저. '어드민'은 쓰지 않는다 |
| 당번표 | 앱 이름(NXT 당번표). 화면 안에서 표는 '근무표'라고 부른다 |
| 장중관제 | 장중 시간대(08:30~18:00) 10칸의 관제 당번. 화면에서 좁은 곳은 "관제" |
| 칸 | 근무조 4개 + 장중관제 10개 + 점심당번 = 하루 15칸 |
| 근무표 | 회차·부서·근무 정의(이름·시각)를 가진 단위. IT 당번표가 첫 근무표 |
| 점심당번 | 그날 점심 자리를 지키는 당번. 가장 이른 근무조를 따라가고 인원 제한이 없다. 점심 시각은 부서마다 |
| 사유 | (휴가)·(출장)·(교육). 붙으면 그날 근무로 치지 않는다. 근무표 화면에서는 "이름(휴가)"에 취소선·회색(배경과 대비 4.5:1 이상), 변경 내역 표시를 숨김으로 하면 안 보인다(흐리게로 하면 옅게) |
| 휴장일 | 공휴일·대체공휴일·선거일·임시공휴일·12/31. 모든 근무표 공통 |
| 근무 없음 | 근무표 하나만 쉬는 날. 날 메모로 적으면 그날 근무를 지우고 글을 보인다. 필요한 사람은 그 뒤에 넣는다 |
| 편차 | 장중관제를 가장 많이 받은 사람과 가장 적게 받은 사람의 횟수 차이. 목표 2 이하 |
| 배포 | 생성된 회차를 근무표에 올리는 것. 덮어쓰기 시작일부터 겹치는 기존 근무표를 대신한다 |
| 배포 취소 | 가장 최근 배포를 되돌리는 것. 덮어썼던 근무가 되살아난다 |
| 근무 변경 | 배포된 근무의 교체(A>B)·추가(+B)·제거(취소선)·맞교환. 모두 기록된다 |
| 멤버 코드 | 사람마다 정한 코드이자 로그인 아이디 |
| 근무표 관리자 | 그 근무표 관리 그룹 멤버. 관리자 계정 = 어느 근무표든 관리 그룹 멤버인 계정(근무표 관리자가 [근무표 설정]에서 다룰 수 없고 슈퍼유저가 다룬다) |
| 입력 담당자 | 부서 입력 그룹 멤버. 취합 중 회차에 자기 부서 출근표를 넣는다. 없으면 근무표 관리자만 입력 |
| 바꿀 수 있는 근무표 | 내 부서의 근무표(오늘 이후)이거나 내가 관리하는 근무표 |
| 내 근무표 | 내 부서의 근무표(부서가 없으면 내가 관리하는 첫 근무표, 그것도 없으면 첫 근무표). 근무표 화면의 기본 |
| 고른 근무표 | 근무표 화면에서 겹쳐 볼 근무표 목록(드롭다운에서 고르고 [보기], 다음에도 그대로). 내 근무표가 맨 위 |
| 구역 | 겹쳐 본 화면의 날짜 칸 안에서 근무표 하나가 차지하는 부분(이름표 → 날 메모 → 칸) |
