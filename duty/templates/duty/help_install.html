휴대폰·PC에 앱으로 설치하기

설치하면 홈 화면(PC는 바탕화면)의 "NXT 당번표" 아이콘으로 바로 열리고, 주소창 없이 앱처럼 보입니다. 앱 스토어에서 내려받는 앱이 아니라 따로 업데이트할 것이 없고, 언제든 지울 수 있습니다.

안드로이드 (Chrome)

  1. Chrome으로 당번표 주소를 엽니다.
  2. 오른쪽 위 ⋮ 메뉴 → [홈 화면에 추가] 또는 [앱 설치] → [설치]를 누릅니다.
  3. 홈 화면의 "NXT 당번표" 아이콘으로 엽니다. 로그인은 Chrome과 같이 씁니다.

안드로이드 (삼성 인터넷)

  1. 삼성 인터넷으로 당번표 주소를 엽니다.
  2. 아래쪽 ≡ 메뉴 → [현재 페이지 추가] → [홈 화면]을 누릅니다.

아이폰·아이패드 (Safari)

  1. 꼭 Safari로 엽니다. 카카오톡·네이버 앱 안에서 열었다면 메뉴의 [Safari로 열기]를 누릅니다.
  2. 아래쪽 공유 버튼(네모에 위쪽 화살표) → 목록을 내려 [홈 화면에 추가] → [추가]를 누릅니다.
  3. 홈 화면에 생긴 "NXT 당번표" 앱을 열고 다시 로그인합니다(Safari와 로그인이 따로입니다).
  4. 아이폰은 이렇게 설치한 앱에서만 푸시 알림을 받을 수 있습니다(iOS 16.4 이상).

PC (Chrome, Edge)

  1. 당번표를 연 채로 주소창 오른쪽 끝의 설치 아이콘(모니터 모양)을 누르고 [설치]를 누릅니다.
  2. 아이콘이 없으면 오른쪽 위 메뉴(Chrome ⋮, Edge …)에서 "설치" 또는 "앱으로 설치"가 들어간 항목을 누릅니다.
  3. 바탕화면·시작 메뉴에 "NXT 당번표"가 생깁니다.

자주 묻는 것

  • 설치 메뉴가 안 보여요 — 카카오톡·네이버 같은 앱 안의 브라우저에서는 설치할 수 없습니다. Chrome(아이폰은 Safari)으로 다시 여세요. 회사 PC는 보안 정책으로 막혀 있을 수 있습니다.
  • 업데이트는요? — 따로 할 것이 없습니다. 열 때마다 최신 화면입니다.
  • 지우고 싶어요 — 휴대폰은 아이콘을 길게 눌러 [삭제] 또는 [앱 제거], PC는 앱 창 오른쪽 위 메뉴의 [제거]. 지워도 근무표와 알림 설정은 그대로입니다(아이폰 푸시는 다시 설치한 앱에서 다시 등록).
  • 알림도 받고 싶어요 — 휴대폰·PC 푸시 알림 받기(로그인 필요).
