연결하기

  1. 휴대폰이나 PC에 텔레그램 앱을 설치하고 로그인합니다.
  2. 알림 설정 화면에서 [텔레그램 연결]을 누릅니다. 새 창(또는 텔레그램 앱)에서 {% if bot_username %}@{{ bot_username }}{% else %}알림 봇{% endif %} 대화창이 열리면 아래의 [시작](START)을 누릅니다.
  3. 웹 화면으로 돌아와 [연결 확인]을 누릅니다. "텔레그램이 연결되었습니다."가 보이고 텔레그램에 "[연결 완료]" 메시지가 오면 끝입니다.
  4. 알림 설정 화면의 알림 규칙을 확인합니다. 기본 규칙(전날 18:00, 시작 2시간 전)이 있으며, 필요하면 수정·추가합니다.

연결 코드는 10분 동안 유효하고, [텔레그램 연결]을 다시 누르면 이전 코드는 쓸 수 없습니다. 링크를 다른 사람에게 공유하지 마세요.

고급: chat_id 직접 입력

  1. 먼저 {% if bot_username %}@{{ bot_username }}{% else %}알림 봇{% endif %}과의 대화에서 [시작]을 누릅니다.
  2. 내 개인 채팅 chat_id(양수 숫자)는 관리자에게 확인받습니다.
  3. 알림 설정 화면의 "고급: chat_id 직접 입력"에 넣고 [저장 및 테스트]를 누릅니다. 테스트 메시지가 오면 연결된 것입니다.

자주 묻는 문제

  • "아직 확인되지 않았습니다" — 봇 대화창에서 [시작]을 누르지 않았습니다. 텔레그램에서 [시작]을 누른 뒤 다시 [연결 확인]을 누르세요. [시작] 버튼이 안 보이면 [텔레그램 연결]을 다시 눌러 새 링크로 여세요.
  • "연결 코드가 만료되었습니다" — 10분이 지났거나 [텔레그램 연결]을 다시 눌렀습니다. [텔레그램 연결]부터 다시 하세요.
  • 봇을 차단함 — 텔레그램에서 봇 차단을 해제한 뒤 다시 연결하세요. 차단 중에는 알림이 오지 않습니다.
  • 그룹방 — 그룹 채팅은 연결할 수 없습니다. 봇과의 1:1 대화에서 [시작]을 누르세요.
  • "잠시 후 다시 시도하세요" — 연결 확인·테스트는 30초에 한 번만 할 수 있습니다.
