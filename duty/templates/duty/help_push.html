웹 푸시 알림 받는 방법

푸시는 기기(브라우저)마다 따로 등록합니다. 알림을 받을 기기마다 아래 단계를 한 번씩 하세요.

안드로이드 (Chrome)

  1. Chrome으로 당번표에 로그인하고 알림 설정을 엽니다.
  2. [이 기기에서 푸시 받기]를 누르고 알림 권한 요청에서 [허용]을 누릅니다.
  3. 기기 목록에 "Chrome / Android"가 생기면 [테스트 푸시]를 눌러 알림이 오는지 확인합니다.

PC (Chrome, Firefox)

  1. Chrome 또는 Firefox로 당번표에 로그인하고 알림 설정을 엽니다.
  2. [이 기기에서 푸시 받기]를 누르고 주소창 옆 권한 요청에서 [허용]을 누릅니다.
  3. [테스트 푸시]로 확인합니다. 브라우저를 완전히 닫으면 알림이 오지 않을 수 있습니다.

아이폰·아이패드 (iOS 16.4 이상)

  1. Safari로 당번표를 엽니다.
  2. 아래쪽 공유 버튼 → [홈 화면에 추가]를 누릅니다.
  3. 홈 화면에 생긴 "당번표" 앱을 열고 다시 로그인합니다(Safari와 로그인이 따로입니다).
  4. 앱 안에서 알림 설정 → [이 기기에서 푸시 받기] → [허용]을 누릅니다.

Safari 탭에서는 푸시를 받을 수 없습니다. 반드시 홈 화면 앱에서 등록하세요.

알림 권한을 거부했을 때 다시 허용하기

  • 안드로이드 Chrome — 주소창 왼쪽 아이콘 → [권한] → [알림]을 허용으로 바꿉니다.
  • PC Chrome — 주소창 왼쪽 아이콘 → [사이트 설정] → [알림]을 [허용]으로 바꾸고 새로고침합니다.
  • PC Firefox — 주소창 왼쪽 자물쇠 아이콘 → 알림 권한의 [차단] 표시를 지우고 새로고침합니다.
  • 아이폰·아이패드 — 설정 → 알림 → "당번표"에서 [알림 허용]을 켭니다.

다시 허용한 뒤 [이 기기에서 푸시 받기]를 한 번 더 누르세요.

테스트 푸시가 안 올 때

  • 기기 목록에 이 기기가 있는지 확인합니다. 없으면 [이 기기에서 푸시 받기]를 다시 누릅니다.
  • 기기의 방해 금지·집중 모드, 절전 모드를 끄고 다시 시도합니다.
  • 운영체제 설정에서 브라우저(또는 "당번표" 앱)의 알림이 켜져 있는지 확인합니다.
  • "실패"로 나오면 [이 기기 해제] 후 다시 등록합니다. 만료된 기기는 목록에서 자동으로 지워집니다.
  • 회사 PC는 보안 정책으로 푸시가 막혀 있을 수 있습니다. 휴대폰으로 등록하세요.

로그아웃해도 등록한 기기에는 알림이 계속 오고, 잠금 화면에 이름이 보일 수 있습니다. 기기를 바꾸거나 반납할 때는 알림 설정에서 해당 기기를 삭제하세요.
